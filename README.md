# 🛒 Shop Simulator

A 3D Shop Simulator game developed using **Unreal Engine 5.8**.

This project focuses on creating an interactive shopping environment with game assets, blueprints, animations, materials, and gameplay systems.

## 🎮 About The Project

Shop Simulator is a game development project built in Unreal Engine. It is designed to provide an interactive shop simulation experience.

The project is developed as part of a game development initiative to explore Unreal Engine, Blueprint scripting, asset management, and 3D game development.

## 🛠️ Built With

- **Game Engine:** Unreal Engine 5.8
- **Scripting:** Unreal Engine Blueprints
- **Programming Environment:** Unreal Editor
- **Version Control:** Git & GitHub
- **Platform:** PC / Windows

## 🚀 Getting Started

### Prerequisites

- Windows PC
- Unreal Engine 5.8
- Git / GitHub Desktop

### Installation

1. Clone or download this repository.
2. Locate `CollegeProjectKL.uproject`.
3. Open the project using Unreal Engine 5.8.
4. Allow Unreal Engine to load and process the project files.
5. Open the required level and start exploring the project.
